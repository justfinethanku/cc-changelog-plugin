# 2026-11-06 - Pin reviewed commits for push and recovery
**Keywords:** [BUG_FIX] [PLUGIN] [SECURITY] [TESTING]
**Session:** FLEET-533, Codex burn A lane 6, security pass 2

## What changed
- Replace moving-branch pushes with a saved full commit ID and destination branch.
- Keep retries on that same snapshot and preserve fast-forward rejection.
- Override tag following, remote mirroring and submodule recursion for this single-branch operation.
- Release plugin version 1.0.4.

## Why
A local branch can advance between commit review and push, including during a retry after rejection. The previous branch-name command then publishes the newer tip. A local bare-remote probe reproduced publication of a synthetic unreviewed file. The new command publishes the reviewed object even if the working branch advances or HEAD is detached.

## Testing notes
All 18 Git/package tests passed, including six new push behaviors against local bare remotes. They cover moving HEAD, detached HEAD, remote rejection and idempotent retry, remote advancement, configured extra refs, invalid inputs and staged-work preservation. Mutations restoring a moving source or tag following fail the new tests. CLI package validation and installation passed without a model request.

This push fix does not implement write transactions or commit snapshot isolation. No authenticated model execution or production data loss is claimed.
